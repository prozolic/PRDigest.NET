### [#132846](https://github.com/dotnet/runtime/pull/132846) Use rolling Windows queue for latest Windows tests {#132846}
- 作成者: [@agocke](https://github.com/agocke)
- 作成日時: 2026年08月27日 18:23:57(UTC)
- マージ日時: 2026年08月29日 22:20:32(UTC)
- ラベル: <a style="text-decoration:none;" href="../../labels/area-Infrastructure/index.html"><span style="background-color: #d4c5f9; color: #000000; display: inline-block; padding: 0 7px; font-size:12px; font-weight:500; line-height:18px; border-radius:2em; border:1px solid transparent;">area-Infrastructure</span></a>
#### 概要
Helix CI/CDパイプラインのWindows テストキュー設定を更新し、最新のWindows x64 公開エイリアス (`helix_windows_x64_latest`) を、バージョン固定のWindows 11クライアントキューから、ローリング実行時キュー (`Windows.Amd64.Open.rt`) に変更。CoreCLRおよびライブラリのパイプラインを、中央集中管理されたキュー変数（Windows x64/CET/ARM64）を使用するよう統一。

#### 変更内容
- **eng/pipelines/helix-platforms.yml**: `helix_windows_x64_latest` を `Windows.11.Amd64.Client.Open` から `Windows.Amd64.Open.rt` に変更。明示的にバージョン指定されたキュー（Windows 10、Server、CET、ARM64、Nano、`oldest` エイリアス）は変更なし。
- **eng/pipelines/coreclr/templates/helix-queues-setup.yml**: CoreCLRのキュー選択を、ハードコードされたキュー名から中央集中管理の変数（`helix_windows_x64_latest`、`helix_windows_x64_latest_cet`、`helix_windows_arm64_latest*`）を使用するよう更新。
- **eng/pipelines/libraries/helix-queues-setup.yml**: ライブラリの主要なWindows x64テストを `$(helix_windows_x64_latest)` ローリングエイリアス経由にルーティング。

#### パフォーマンスへの影響
影響なし。本変更はテストインフラストラクチャの管理・統一を目的としており、ランタイム性能に直接的な影響はありません。

#### 関連Issue
[#132328](https://github.com/dotnet/runtime/issues/132328) (ローリングキューの事前検証)

#### その他
Copilotコードレビューにより、複数の中程度から低重要度の指摘が挙げられています：
- CoreCLRの内部Windows x64キュー選択がWindows 10から最新（Windows 11）に変更されることについて、意図的な変更か確認が必要
- ライブラリのパイプラインでServer 2025キューが明示的なキュー名からローリングエイリアスに置き換わることについての確認が必要
- コメントヘッダーの曖昧さの改善提案

検証方法：`git diff --check` と キュー マッピング アサーション。
