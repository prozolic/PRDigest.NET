### [#131878](https://github.com/dotnet/runtime/pull/131878) Don't show SYSLIB1015 when no template given {#131878}
- 作成者: [@rosebyte](https://github.com/rosebyte)
- 作成日時: 2026年08月05日 14:42:58(UTC)
- マージ日時: 2026年09月02日 13:31:42(UTC)
- ラベル: <a style="text-decoration:none;" href="../../labels/area-Extensions-Logging/index.html"><span style="background-color: #d4c5f9; color: #000000; display: inline-block; padding: 0 7px; font-size:12px; font-weight:500; line-height:18px; border-radius:2em; border:1px solid transparent;">area-Extensions-Logging</span></a>
#### 概要
`[LoggerMessage]` ソースジェネレータが、メッセージテンプレートなしのロギングメソッドに対して不正に `SYSLIB1015` 警告を発生させていた問題を修正します。メッセージなしでパラメータをキャプチャするパターン（構造化ログのみ）は正当で広く使われていますが、`TreatWarningsAsErrors` を使用するプロジェクトでビルド失敗を引き起こしていました。

```csharp
[LoggerMessage(LogLevel.Critical)]
public static partial void FoodRecallNotice(
    this ILogger logger,
    string brandName, string productDescription, string productType);
// 修正前：5個のパラメータごとに SYSLIB1015 警告
// 修正後：警告なし（メッセージなし時は診断を抑制）
```

#### 変更内容
- **LoggerMessageGenerator.Parser.cs**: メソッドごとに `hasMessage` フラグを計算し、`ArgumentHasNoCorrespondingTemplate` の診断呼び出しをガードするよう修正（破壊的変更なし）
- **LoggerMessageAttribute.cs**: メッセージ省略時の構造化ログのみのパターンについてXMLドキュメント追加
- **テストクラス群**: メッセージなしのロギングメソッドをテストするメソッドを再有効化。メッセージ空文字列 (`""`)、`null`、省略時は警告なし；メッセージあり時は既存動作を保持

#### パフォーマンスへの影響
影響なし

#### 関連Issue
[#101687](https://github.com/dotnet/runtime/issues/101687)

#### その他
本修正は**内部実装（ソースジェネレータ）の改善**であり、公開APIは変更されません。メッセージなし時の `SYSLIB1015` 診断は本来不適切だったもの（診断テキスト「ロギングメッセージから参照されない」は、メッセージが存在しない場合に成立しない）で、Microsoft.Extensions.Telemetry の同等診断 `LOGGEN011` が `Info` レベルであることとの一貫性もあります。既存のメッセージテンプレートがある場合の動作は完全に保持されます。
