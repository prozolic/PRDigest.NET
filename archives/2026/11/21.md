#### 概要
`AggregationManager` におけるインストゥルメント登録の競合状態を修正するPRです。リスナー起動時、インストゥルメント作成時、共有セッションの再列挙時にpublicationコールバックが重複して呼ばれ、有効化済みインストゥルメントを保持する辞書が同期なしでアクセスされていました。また、メンバーシップ確認後に有効化する実装のため、重複した enable 呼び出しが発生し得ました。

- 辞書を `ConcurrentDictionary` に変更

- `src/libraries/System.Diagnostics.DiagnosticSource/src/System/Diagnostics/Metrics/AggregationManager.cs`（+5/-9）: 有効化済みインストゥルメントの管理を `ConcurrentDictionary` ＋ `TryAdd`/`TryRemove` に変更

### [#136452](https://github.com/dotnet/runtime/pull/136452) Fix DispatchProxy pointer parameters and returns {#136452}
- 作成者: [@caraioniurie47](https://github.com/caraioniurie47)
- 作成日時: 2026年10月25日 20:18:27(UTC)
- マージ日時: 2026年11月21日 04:37:02(UTC)
- ラベル: <a style="text-decoration:none;" href="../../labels/area-System.Reflection/index.html"><span style="background-color: #d4c5f9; color: #000000; display: inline-block; padding: 0 7px; font-size:12px; font-weight:500; line-height:18px; border-radius:2em; border:1px solid transparent;">area-System.Reflection</span></a> <a style="text-decoration:none;" href="../../labels/community-contribution/index.html"><span style="background-color: #c2e0c6; color: #000000; display: inline-block; padding: 0 7px; font-size:12px; font-weight:500; line-height:18px; border-radius:2em; border:1px solid transparent;">community-contribution</span></a>
#### 概要
`DispatchProxy` が生成するプロキシメソッドで、ポインタ型のパラメータ・戻り値の扱いが誤っていた問題を修正します。従来は生のポインタに対して `castclass object` / `castclass <ポインタ型>` を行っていたため、CoreCLR では非 null のポインタ引数で `NullReferenceException`、`Invoke` が返したポインタで `InvalidCastException` が発生し、Mono の JIT では毎回 `InvalidProgramException` で拒否されていました。

修正後のポインタの受け渡しは以下のとおりです。
- **引数**: `Invoke` の `args` には、パラメータ型の `System.Reflection.Pointer`（`Pointer.Box`）として渡されます。null ポインタも同様です（従来 CoreCLR では `null` として渡されていました）。`ref` / `in` のポインタ引数も現在値が同じ形で渡されます。
- **戻り値、および `ref`/`out` ポインタの `args` への書き戻し**: `Pointer`、`IntPtr`、または null ポインタを表す `null` を受け付けます。それ以外は `IntPtr` としてアンボックスされるため、`int` や `string` では `InvalidCastException` になります。
- `Pointer` の型は `Pointer.PointerType`（#137769）で読み取り、ターゲット型に代入可能でなければ `InvalidCastException` をスローします。`void*` ターゲットは任意のポインタ型の `Pointer` を受け付けます。

```csharp
// Invoke 内で method.Invoke(target, args) と転送する場合、
// 値渡しのポインタ引数とポインタ戻り値はそのまま動作する
```

`ref`/`out`/`in` ポインタパラメータを持つメソッドを `MethodInfo.Invoke` 経由で転送する場合は、従来どおり失敗します（本 PR では対象外）。

#### 変更内容
- `DispatchProxyGenerator.cs`（+71/-10）: ポインタのボックス化・アンボックス化を行う IL 生成を追加。アンボックスは `DispatchProxyGenerator` 内の C# メソッド経由で行われ、その呼び出しを生成する場合は、プロキシアセンブリに System.Reflection.DispatchProxy 向けの `IgnoresAccessChecksTo` 属性が付与されます。ポインタを含まないメソッドと関数ポインタの IL は変更なし。
- `Strings.resx`（+3/-0）: 関連するリソース文字列を追加。
- `DispatchProxyTests.cs`（+276/-0）: ポインタ引数、戻り値、`ref`/`out`/`in`、`void*`、`int**`、`MethodInfo.Invoke` 経由の転送、新しい `AssemblyLoadContext` でのポインタプロキシのテストを追加。
- `TestTypes.cs`（+37/-0）: テスト用のポインタインターフェースと実装を追加。
- `System.Reflection.DispatchProxy.Tests.csproj`（+1/-0）: unsafe コードを有効化。
- `TrimmingTests/DispatchProxyTest.cs`（+10/-2）: トリミングテストでポインタメソッドを呼び出すよう変更。

影響なし（ベンチマーク結果の記載もありません）。

#### その他
- **互換性**: CoreCLR で null ポインタ引数が従来 `null` で渡されていたものが `Pointer` として渡されるようになります。
- **Mono**: Mono はプロキシアセンブリの `IgnoresAccessChecksTo` 属性を一度しか読み込まないため、後から追加された属性（ポインタをアンボックスするプロキシや internal 型のプロキシ）を認識できません。このため、新しい `DispatchProxyTests` のテストは Mono ではスキップされます。
