### [#137112](https://github.com/dotnet/runtime/pull/137112) \[wasm\] Take wasm SIMD instruction sets from the compiler; default relaxed SIMD on for WASI {#137112}
- 作成者: [@lewing](https://github.com/lewing)
- 作成日時: 2026年11月06日 22:10:03(UTC)
- マージ日時: 2026年11月15日 21:08:14(UTC)
- ラベル: <a style="text-decoration:none;" href="../../labels/arch-wasm/index.html"><span style="background-color: #eb6420; color: #ffffff; display: inline-block; padding: 0 7px; font-size:12px; font-weight:500; line-height:18px; border-radius:2em; border:1px solid transparent;">arch-wasm</span></a> <a style="text-decoration:none;" href="../../labels/area-ReadyToRun/index.html"><span style="background-color: #d4c5f9; color: #000000; display: inline-block; padding: 0 7px; font-size:12px; font-weight:500; line-height:18px; border-radius:2em; border:1px solid transparent;">area-ReadyToRun</span></a> <a style="text-decoration:none;" href="../../labels/linkable-framework/index.html"><span style="background-color: #1ae80b; color: #000000; display: inline-block; padding: 0 7px; font-size:12px; font-weight:500; line-height:18px; border-radius:2em; border:1px solid transparent;">linkable-framework</span></a> <a style="text-decoration:none;" href="../../labels/os-wasi/index.html"><span style="background-color: #fef2c0; color: #000000; display: inline-block; padding: 0 7px; font-size:12px; font-weight:500; line-height:18px; border-radius:2em; border:1px solid transparent;">os-wasi</span></a>
#### 概要
wasm SIMD の命令セットをコンパイラ側（`InstructionSetHelpers`）から取得する方式に変更し、WASI では CoreCLR ReadyToRun と NativeAOT の両方で relaxed SIMD をデフォルト有効にします。ブラウザは opt-in のまま、Mono は変更なしです。

| ターゲット | Relaxed SIMD | オプトアウト / オプトイン |
|---|---|---|
| CoreCLR WASI (R2R) | 有効 | `PublishReadyToRunInstructionSet=-relaxed-simd` |
| NativeAOT WASI | 有効 | `IlcInstructionSet=-relaxed-simd` |
| CoreCLR browser (R2R) | 無効 | `PublishReadyToRunInstructionSet=relaxed-simd` |
| Mono | 未実装 | — |

#### 変更内容
- **命令セット決定**: `InstructionSetHelpers` が wasm32 WASI のデフォルトに `relaxed-simd` を追加し、crossgen2 / ILC が自動で採用します。
- **`PublishReadyToRunInstructionSet`**: crossgen2 の `--instruction-set:` に対応する汎用プロパティ（`+x`/`-x` 指定可）を追加しました。ブラウザ専用だった `WasmEnableRelaxedSimd` は、対応するネイティブフラグ（`-mrelaxed-simd` など）、再リンクのトリガー、ワークロード要件とともに削除されました。wasm-opt は常に relaxed SIMD を有効化します。
- **イメージの整合性チェック**: wasm には実行時の ISA 検出がないため、ランタイムは CoreLib の R2R イメージが前提とする命令セットを採用し、他のイメージをそれと照合して不一致を拒否します。これに伴い browserhost の設定プロパティ経由のフック（`browserhost.cpp`）を削除しました。
- **NativeAOT**: CoreLib が wasm intrinsics をコンパイルするようになり、ILC が `System.Runtime.Intrinsics.Wasm` の型を命令セットにマップします。JIT は NativeAOT ABI 下で wasm ISA サポートを厳密に扱うため、`IsSupported` はコンパイル時定数になります。`SupportsWasmIntrinsics` は全 wasm CoreLib で true、relaxed SIMD は Mono 以外で true です。
- **`WasiEnableCompositeR2R` を削除**: WASI R2R は元々 `PublishReadyToRunComposite=true` を要求するため、ホストのリンクフラグは `PublishReadyToRun` だけに依存します。
- **CoreCLR では `IsSupported` の trimmer 折りたたみを行わない**: JIT とインタプリタがメソッド単位でサポート可否を決めるため、折りたたむとインタプリタ実行コードが intrinsic パスを通って例外を投げる恐れがあります。トリム済み WASI R2R アプリでの削減量は R2R コードで約 2.7 KB（IL で 6 KB）でした。substitutions は Mono のみ維持されます。
- **インクリメンタル publish**: CoreLib の crossgen ステップが `PublishReadyToRunInstructionSet` を記録し、変更時に CoreLib を再コンパイルします。アプリイメージの再コンパイル問題は #137563 で対応予定です。
- **SDK 側のマッピングは未反映**: アプリの publish が使う SDK 側の crossgen2 targets は `PublishReadyToRunInstructionSet` をまだマップしていません（dotnet/sdk#57127）。反映されるまで、アプリ publish ではブラウザの opt-in と WASI の opt-out が機能せず、`WasmSIMDTests.PublishRelaxedSimdEnabledCoreClr` は #137571 のため無効化されています。リポジトリ内ビルドは対応済みです。
- **テスト関連**:
  - `hardware-intrinsics-wasm` パイプラインに WASI レッグを追加しました（`WholeProgramCompositeBuildMode`）。ブラウザレッグはこれまでプロパティが転送されず、実際には relaxed SIMD が有効になっていませんでした。
  - `System.Runtime.Intrinsics.Tests` を WASI 向けにビルドし、`PackedSimd`/`RelaxedSimd` テストをブラウザと WASI で実行します。
  - `Wasm.Build.Tests` に `PublishRelaxedSimdCoreClr` を追加しました。
  - 他の WASI R2R ランタイムテストは CoreLib がインタプリタ実行のため（#134949）ベースライン命令セットを使い、`PackedSimdTests` の 2 件は隔離のままです。
- 主な変更ファイル: `InstructionSetHelpers.cs`、`InstructionSetSupport.cs`、`hwintrinsic.cpp`、`codeman.cpp/.h`、`jitinterface.cpp`、`WasiApp.CoreCLR.targets`、`BrowserWasmApp.CoreCLR.targets`、`crossgen-corelib.proj`、`WasmSIMDTests.cs`、関連パイプライン YAML、ドキュメント（`wasi-r2r.md`）など。

#### パフォーマンスへの影響
ベンチマーク結果は記載されていません。トリム済み WASI R2R アプリで `IsSupported` を折りたたまない場合の影響は、約 2.7 KB の R2R コード増（IL で 6 KB）と測定されています。
